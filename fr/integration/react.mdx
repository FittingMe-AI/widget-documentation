## Placer l’intégration hors de React

Gardez l’intégration dans le modèle de page. Ajoutez un point de montage React à côté du conteneur du widget :

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Example product page</title>
</head>
<body>
  <!-- Render these siblings in the page template, outside React. -->
  <div id="try-on-react-root"></div>
  <div id="fittingme-widget-container"></div>
  <script src="https://widget.fittingme.ai/v5/fittingme-loader.js"
    data-api-base="https://api.fittingme.ai"
    data-retailer-key="YOUR_PUBLISHABLE_KEY"
    data-product-id="YOUR_PRODUCT_ID"
    data-garment-image-urls="https://images.example.com/YOUR_GARMENT.jpg"
    data-journey="tryon"
    data-locale="en"
    data-trigger-mode="widget"
    data-container="#fittingme-widget-container"></script>
</body>
</html>
```

Montez React dans `try-on-react-root`. Ne laissez jamais React afficher ou supprimer le conteneur du widget.

## Observer l’état depuis React

L’effet gère uniquement son abonnement et ses minuteries. N’appelez ni `close()` ni `destroy()` dans son nettoyage. Le délai de 15 secondes est votre choix.

```jsx
'use client';
import { useEffect, useState } from 'react';

export function TryOnStatus() {
  const [message, setMessage] = useState('Loading try-on…');

  useEffect(() => {
    let unsubscribe = () => {};
    let poll;
    let connected = false;
    let expired = false;
    setMessage('Loading try-on…');
    const deadline = setTimeout(() => {
      expired = true;
      clearTimeout(poll);
      setMessage('Try-on is taking longer than expected. Reload to retry.');
    }, 15000);

    const connect = () => {
      if (expired || connected) return;
      const container = document.getElementById('fittingme-widget-container');
      const fm = window.FittingMe;
      if (!container || !fm?.resolve(container)) {
        poll = setTimeout(connect, 100);
        return;
      }
      connected = true;
      unsubscribe = fm.on(event => {
        if (event.embed !== container || event.type !== 'bootstrap') return;
        clearTimeout(deadline);
        setMessage(event.outcome === 'eligible' ? '' :
          event.outcome === 'ineligible' ? 'Try-on is unavailable for this product.' :
          'Try-on is temporarily unavailable.');
      });
    };
    connect();

    return () => {
      expired = true;
      clearTimeout(poll);
      clearTimeout(deadline);
      unsubscribe();
      // The page owns the embed. Leave its connected DOM and loader intact.
    };
  }, []);

  return <p role="status">{message}</p>;
}
```

## Changer de produit en rechargeant la page

- Autre produit ou autre image de couleur : chargez sa page.
- Autre taille, même image : gardez l’intégration.
- Autre contenu de la page : gardez l’intégration.

Désactivez l’interception du routeur sur les liens produit. Le loader n’a pas de méthode pour changer le produit ou la taille. Modifier les attributs du script ou transmettre une variante à `open()` ne change pas le vêtement.

## Fermer avant de remplacer

Pour remplacer une intégration sans recharger la page, gardez son conteneur jusqu’à la réussite de l’étape 4 :

1. Abonnez-vous à l’événement `closed` de l’intégration.
2. Appelez `FittingMe.close(container)` et vérifiez le verdict.
3. Attendez `closed` avec un délai maximal. Si le délai expire, gardez l’intégration et proposez de recharger la page.
4. Appelez `destroy(container)`. Supprimez le conteneur seulement après le retour de `accepted`.

Appeler `close()` puis `destroy()` immédiatement renvoie `drawer_open`. Supprimer alors le conteneur peut bloquer le défilement de la page. Ne détruisez pas l’intégration et ne vous désabonnez pas dans le gestionnaire de `closed` : un `completed` suivant peut être perdu. Consultez les [limites de complétion](/fr/reference/events#la-complétion-n’est-pas-une-conversion).

## Plusieurs intégrations sur une page

Donnez à chaque intégration son propre conteneur et son propre script. Filtrez les événements sur l’élément conteneur :

```javascript
const jacket = document.getElementById('jacket-tryon');
const unsubscribe = window.FittingMe.on(event => {
  if (event.embed !== jacket) return;
  // Handle this embed's milestone using your own product context.
});
```

Un seul panneau s’ouvre à la fois. Le loader ignore un deuxième script dans le même conteneur actif.

## Vérifier

- Montez, démontez et remontez le composant d’état avant l’arrivée du loader.
- Vérifiez que le mode Strict et la version de production affichent un seul widget.
- Ouvrez le panneau, démontez le composant et fermez le panneau. Le défilement de la page revient.
- Suivez un lien produit. Le rechargement complet affiche le bon produit.
- Bloquez le loader. Le composant d’état cesse d’attendre après son délai.
