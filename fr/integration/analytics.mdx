## Déterminer quoi mesurer

| Question | Indicateur |
| --- | --- |
| Ce produit peut-il proposer l’essayage ? | `bootstrap` avec `outcome: 'eligible'`. |
| Un acheteur a-t-il ouvert l’essayage ? | `opened`. |
| Le panneau s’est-il fermé ? | `closed`. |
| S’est-il fermé sur un résultat terminé ? | [`completed`](/fr/reference/events#la-complétion-n’est-pas-une-conversion), après `closed`. |
| Combien de rendus ont été affichés ? | Valeurs distinctes de `try_on_reference` des événements `tryon_result_revealed`. [Indicatif, jamais une facture](/fr/reference/events#rendus-d’essayage-affichés). |
| L’acheteur a-t-il acheté ? | Vos propres événements de panier et de commande. |

Un `bootstrap` rejoué n’est pas une visite d’acheteur.

## Ajouter un adaptateur de suivi

Exécutez ce code avant d’activer un déclencheur personnalisé. Il attend le loader jusqu’à 15 secondes.

```javascript
const container = document.getElementById('fittingme-widget-container');
const productId = 'YOUR_PRODUCT_ID';
let analyticsAllowed = false;

// Connect this function to your storefront's consent manager.
function setTryOnAnalyticsConsent(allowed) {
  analyticsAllowed = allowed === true;
}

const eventNames = {
  opened: 'fittingme_opened',
  closed: 'fittingme_closed',
  completed: 'fittingme_completed_result_closed',
  tryon_result_revealed: 'fittingme_tryon_result_revealed',
};

// The loader script is async: wait up to 15 seconds for window.FittingMe.
let unsubscribe = () => {};
(() => {
  let poll;
  const deadline = setTimeout(() => clearTimeout(poll), 15000);
  const connect = () => {
    const fm = window.FittingMe;
    if (!fm) {
      poll = setTimeout(connect, 100);
      return;
    }
    clearTimeout(deadline);
    unsubscribe = fm.on(event => {
      if (event.embed !== container || !analyticsAllowed) return;
      const name = eventNames[event.type];
      if (!name) return;
      const record = { event: name, product_id: productId };
      if (event.type === 'opened') record.open_origin = event.origin;
      if (event.type === 'tryon_result_revealed') record.try_on_reference = event.try_on_reference;
      window.dataLayer = window.dataLayer || [];
      window.dataLayer.push(record);
    });
  };
  connect();
})();

// Keep this subscription for the lifetime of the page-owned embed.
// Do not unsubscribe in a closed handler: completed can follow.
```

Les quatre noms sont les vôtres, et l’ajout à `dataLayer` ne configure aucune destination.

N’envoyez jamais l’élément DOM, la clé d’enseigne, l’URL complète de l’iframe ni le lien de capture. N’envoyez pas non plus le jeton de session, la photo de l’acheteur ni l’URL du résultat. Gardez un seul abonnement par propriétaire pendant toute la vie de l’intégration. Vérifiez le consentement au moment de l’envoi.

## Vérifier les mesures

1. Refusez le consentement et terminez un parcours. Résultat attendu : aucun enregistrement.
2. Donnez le consentement et terminez un nouveau parcours.
3. Fermez le panneau : attendez `closed`, puis `completed`, avec votre produit. Rouvrez et refermez : rien n’est attendu.
4. Gardez le panneau ouvert sur un rendu. Attendez un `fittingme_tryon_result_revealed` avec une `try_on_reference` de 32 caractères.
5. Relancez l’essayage. Attendez une nouvelle référence.
6. Rouvrez, puis rechargez la page sur ce rendu. Résultat attendu : aucun enregistrement.
7. Rechargez et fermez un résultat terminé : attendez une complétion, pas un nouvel essayage. Fermez pendant la génération, puis rouvrez : attendez un enregistrement. Abonnez-vous tard : aucun enregistrement n’est attendu.
8. Comparez les achats avec vos événements de commande. Une complétion n’est jamais une conversion.
