`window.FittingMe` existe après que le loader a accepté sa première balise de script. Avant cela, utilisez les attributs du loader. Transmettez l’élément conteneur ou l’iframe, pas un sélecteur.

```javascript
const container = document.getElementById('fittingme-widget-container');
const fm = window.FittingMe;
const state = fm.resolve(container);
```

## Méthodes

| Méthode | Renvoie | Comportement |
| --- | --- | --- |
| `resolve(element)` | Instantané ou `undefined` | Lit une intégration active. |
| `open(element)` | Verdict | Ouvre le panneau après un amorçage éligible. |
| `close(element)` | Verdict | Ferme le panneau. |
| `destroy(element)` | Verdict | Supprime une intégration fermée. |
| `on(handler)` | Fonction de désabonnement | S’abonne à toutes les intégrations. Filtrez sur `event.embed`. |

Les commandes répondent de façon synchrone. `accepted` n’est pas le résultat : observez les événements. Un `open` avant l’amorçage est refusé, pas mis en attente. Pendant que le panneau est ouvert, `close` puis `destroy` immédiatement renvoie `drawer_open` ([Fermer avant de remplacer](/fr/integration/react#fermer-avant-de-remplacer)). `get()` est une ancienne forme d’appel : utilisez les commandes avec élément.

## Identifiant de corrélation

`window.FittingMe.setCorrelationId(id)` définit la valeur de jointure des [Événements Livrés](/fr/reference/delivered-events#joindre-vos-propres-analyses) pour toutes les intégrations de la page.

- Transmettez de 1 à 128 caractères qui ne commencent pas par `FM_`. Transmettez `""`, `null` ou `undefined` pour l’effacer.
- La dernière valeur l’emporte, qu’elle vienne de cette méthode ou de [`data-correlation-id`](/fr/reference/configuration#attributs-facultatifs).
- Une intégration prend la valeur à l’ouverture de son panneau.
- Une valeur refusée affiche un avertissement et efface l’identifiant.
- Ne mettez jamais un identifiant personnel, comme une adresse e-mail, dans cette valeur.

## Instantané d’état

```javascript
// Shape returned by resolve(container); values shown are illustrative.
({
  embed: container,
  journey: 'tryon',
  outcome: 'eligible',
  drawer_open: false
});
```

`outcome` vaut `undefined` jusqu’à la fin de l’amorçage.

## Verdicts des commandes

| Valeur | Signification |
| --- | --- |
| `accepted` | Le loader a pris en compte la commande. |
| `unknown_embed` | L’élément n’est pas une intégration connue. |
| `embed_destroyed` | L’intégration a été détruite. |
| `bootstrap_incomplete` | L’amorçage est en attente ou indéterminé. |
| `embed_ineligible` | L’intégration ne peut pas s’ouvrir. |
| `fullscreen_unavailable` | Un élément parent bloque l’affichage plein écran. |
| `drawer_open` | La destruction a été demandée alors que le panneau était ouvert. |

## S’abonner

```javascript
const unsubscribe = fm.on(event => {
  if (event.embed !== container) return;
  if (event.type === 'bootstrap') {
    const canOpen = event.outcome === 'eligible';
    // Update your button state using canOpen.
  }
});

// When this subscriber's owner is disposed:
unsubscribe();
```

À l’abonnement, le loader répète le dernier résultat de l’amorçage. Il ne répète pas les autres événements. La répétition s’exécute dans `on()`. Initialisez vos valeurs avant d’appeler `on()`. N’appelez pas la fonction renvoyée depuis le gestionnaire répété.
