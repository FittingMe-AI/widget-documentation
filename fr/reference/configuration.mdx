Chargez `https://widget.fittingme.ai/v5/fittingme-loader.js` une fois par intégration, avec ses attributs sur ce script. Gardez `async` sur ce script : le navigateur lit et affiche alors votre fiche produit, sans attendre FittingMe. L’événement `load` de la page attend toujours le loader et l’iframe du widget.

## Attributs obligatoires

| Attribut | Valeur |
| --- | --- |
| `data-api-base` | Normalement `https://api.fittingme.ai`. |
| `data-retailer-key` | Clé publiable autorisée pour votre nom d’hôte. |
| `data-product-id` | Votre identifiant produit. |
| `data-garment-image-urls` | Une URL HTTPS ou un tableau JSON d’URL du même produit dans la même couleur. |
| `data-journey` | `tryon`. |

Une valeur absente ou vide empêche le montage, sauf pour `data-garment-image-urls`. Sans attribut d’image, l’intégration n’envoie aucune photo de page.

## Attributs facultatifs

| Attribut | Par défaut | Usage |
| --- | --- | --- |
| `data-garment-image-url` | Aucun | Alias déconseillé pour une seule photo. |
| `data-container` | `#fittingme-widget-container` | Sélecteur du conteneur existant. |
| `data-trigger-mode` | `host` | `widget` affiche le point d’accès FittingMe. |
| `data-locale` | Français | La langue du widget, par exemple `en` ou `fr`. Une valeur inconnue donne le français. |
| `data-correlation-id` | Aucun | Votre valeur de jointure pour les [Événements Livrés](/fr/reference/delivered-events#joindre-vos-propres-analyses). |
| `data-qr-code` | Aucun (pas de QR code) | `true` affiche un QR code sur ordinateur : l’acheteur peut envoyer une photo depuis son téléphone. Essayage uniquement. |
| `data-input-gender` | Aucun (pas de genre présélectionné) | `male` ou `female` présélectionne le genre de l’acheteur dans le profil de recommandation de taille. L’acheteur peut modifier ce choix. Recommandation de taille uniquement : l’Essayage ne tient pas compte de ce paramètre. |
| `data-widget-url` | `https://widget.fittingme.ai/tryon/` | Remplacement du document du widget. |

## Validation

- Un attribut `data-*` inconnu affiche une erreur et l’intégration ne se monte pas.
- `data-garment-image-urls` nécessite le loader `/v5/`. Avec un loader plus ancien, l’intégration ne se monte pas.
- La valeur plurielle est une URL simple ou un tableau JSON. Le loader supprime les espaces, retire les doublons en conservant l’ordre et ignore les éléments invalides.
- Chaque URL utilise HTTPS et compte 1 024 caractères au maximum.
- Si les deux attributs d’image sont présents, le loader affiche une erreur de configuration. L’attribut pluriel l’emporte, même vide ou invalide.
- Les images du catalogue passent en premier. Les photos de la page servent de solution de repli.
- Une langue inconnue revient au français. Définissez `data-locale` explicitement.
- `data-correlation-id` compte de 1 à 128 caractères et ne commence pas par `FM_`. Le loader le lit tel quel. Une valeur refusée affiche un avertissement et l’intégration se monte quand même. Pour la modifier, appelez [`setCorrelationId(id)`](/fr/reference/javascript#identifiant-de-corrélation).
- Une valeur de `data-qr-code` autre que `true`, `false` ou vide affiche une erreur et aucun QR code ne s’affiche.
- Une valeur de `data-input-gender` autre que `male`, `female` ou vide affiche une erreur, et aucun genre n’est présélectionné. L’intégration se monte quand même.

N’ajoutez ni `data-host-origin` ni `data-loader-major`. Définissez `data-trigger-mode="widget"` explicitement. Une valeur absente, vide ou inconnue donne le mode hôte.

## Durée de vie

Le loader lit les attributs une seule fois, à l’exécution du script. Utilisez un conteneur unique par intégration, placé avant le script. Pour changer de produit, consultez [Boutiques monopages et dynamiques](/fr/integration/react).
