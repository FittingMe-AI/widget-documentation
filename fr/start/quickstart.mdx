title: "Démarrage rapide : ajouter l’essayage à une fiche produit"
sidebarTitle: "Démarrage rapide"

---

Suivez d’abord les [prérequis](/fr/start/prerequisites).

## 1. Remplacer trois valeurs

| Valeur de remplacement | Remplacez par |
| --- | --- |
| `YOUR_PUBLISHABLE_KEY` | Votre clé d’enseigne. |
| `YOUR_PRODUCT_ID` | L’identifiant du produit. |
| `https://images.example.com/YOUR_GARMENT.jpg` | Une URL d’image publique en HTTPS, aux deux endroits. |

FittingMe doit approuver votre origine pour l’encadrement. Utilisez une URL d’image directe conforme aux [exigences pour l’image](/fr/integration/products#exigences-pour-l’url-de-l’image). En HTML, écrivez `&` sous la forme `&amp;`.

## 2. Ajouter la page

Enregistrez-la sous `try-on.html`.

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Try on this garment</title>
  <style>
    body { margin: 0; padding: 24px; font: 16px/1.6 system-ui, sans-serif; }
    main { max-width: 480px; margin: auto; }
    .product-image { display: block; width: 100%; height: auto; }
  </style>
</head>
<body>
  <main>
    <h1>Example garment</h1>
    <img class="product-image"
      src="https://images.example.com/YOUR_GARMENT.jpg"
      alt="The garment available to try on">
    <div id="fittingme-widget-container"></div>
  </main>
  <script src="https://widget.fittingme.ai/v5/fittingme-loader.js"
    data-api-base="https://api.fittingme.ai"
    data-retailer-key="YOUR_PUBLISHABLE_KEY"
    data-product-id="YOUR_PRODUCT_ID"
    data-garment-image-urls="https://images.example.com/YOUR_GARMENT.jpg"
    data-journey="tryon"
    data-locale="en"
    data-trigger-mode="widget"
    data-container="#fittingme-widget-container"></script>
</body>
</html>
```

Pour plusieurs vues, placez la vue de face en premier :

```html
data-garment-image-urls='["https://images.example.com/FRONT.jpg","https://images.example.com/BACK.jpg"]'
```

Servez-la depuis un nom d’hôte autorisé. Avec une clé `localhost`, exécutez :

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Ouvrez `http://localhost:8080/try-on.html`.

## 3. Vérifier le résultat

1. Chargez la page. Le bouton FittingMe apparaît.
2. Ouvrez l’essayage. Le panneau s’affiche sans être tronqué.
3. Suivez les étapes de consentement et de photo.
4. Lancez la génération. Le résultat apparaît.
5. Fermez le panneau. La page défile normalement.

Réussite : **le bon vêtement apparaît dans un résultat terminé**, et l’acheteur peut revenir.

## En cas de problème

| Observation | Premier point à vérifier |
| --- | --- |
| Aucun bouton | Ordre du conteneur, attributs refusés ou `frame-ancestors` dans la console. |
| L’essayage échoue | Type, taille et redirections de l’image, accès sans connexion. |
| Échec d’accès | Clé, environnement, noms d’hôte et accès à l’essayage. |
| Panneau tronqué ou ouverture refusée | [Transformations des éléments parents](/fr/troubleshooting/symptoms#le-panneau-est-tronqué-ou-refuse-de-s’ouvrir). |
