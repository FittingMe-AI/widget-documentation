Record the build, hostname, browser, device, product, image source and time of each run. Keep keys, photos and capture links out of shared reports.

## Complete the normal journey

| Action | Expected result |
| --- | --- |
| Open a product page | One embed mounts. |
| Open try-on | The drawer opens, and the page stays still. |
| Accept the consent | The photo step opens. |
| Add a test photo | The journey accepts it or shows an error. |
| Start generation | A result or a recoverable failure shows. |
| Inspect the result | It shows the selected garment. |
| Close | Scrolling and focus return. |
| Reopen | The journey resumes or restarts. |

FittingMe runs Cloudflare Turnstile inside the widget iframe. Cloudflare can show a checkbox inside the drawer.

## Verify the desktop-to-phone handoff

Do this only if your Try-On embed sets `data-qr-code="true"`.

1. Show the QR code on desktop.
2. Scan it with a phone, or open its URL in another browser context.
3. Complete the photo step. The desktop resumes.
4. Cancel and retry. The old and new attempts do not mix.

A separate browser context does not test a physical phone.

## Exercise failures deliberately

| Case | Expected result |
| --- | --- |
| Revoked key | The browser blocks the frame. The console shows a `frame-ancestors` refusal. |
| Page not in key domains | The browser blocks the frame. The console shows a `frame-ancestors` refusal. |
| Image host not on the key | FittingMe ignores the page photos. A catalogue product keeps its catalogue photos; a product that FittingMe does not know shows no Try-On button. |
| Unusable garment image | FittingMe uses the catalogue image if the product has one. Otherwise, try-on fails after Start. |
| Product not enabled | Your trigger stays unavailable. |
| Blocked script | The cart and checkout work. |
| Cancel during generation | The drawer offers a next step. |
| Double click | One drawer opens. |
| Colour change | The new garment shows. |
| Photo with no person, such as a product photo | The drawer gives the reason and offers to choose another photo, with no Start. |
| Provider refusal after Start | The change-photo and return-to-product actions show. |

For a revocation test, ask FittingMe for a disposable key. Then ask FittingMe to revoke it. Do not create unsafe content to cause a refusal.

## Check layout and accessibility

Test phone and desktop widths, keyboard, Escape and 200% zoom. Check that Back closes the drawer for each opening method you ship. For product changes, see [single-page and dynamic storefronts](/integration/react).
