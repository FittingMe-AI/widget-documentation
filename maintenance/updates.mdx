## Update an integration

1. Record the working build and key prefix.
2. Read FittingMe's change notice for your update.
3. Apply the change in your test storefront.
4. Run the [journey checks](/testing/journey).
5. Release it. Keep the previous build recoverable.
6. Check a public product page.

The loader URL is stable and has no content hash. Do not keep a vendored or long-cached copy. Ask FittingMe when a change reaches your environment.

## Rotate a retailer key

An Admin rotates keys in **Clés d'environnement** with **Faire tourner…**. The previous key stays valid until revocation. The new key shows once.

1. Store the new key safely.
2. Replace the old value everywhere.
3. Complete a try-on on each hostname.
4. Wait for cached pages to expire.
5. Revoke the previous key when no installation uses it. Revocation breaks every installation that still uses it.

Start only one rotation at a time in a key lineage.

## Disable the entry point

Stop mounting new embeds and hide custom buttons. Keep cart and checkout available. For a mounted page, see [close before replacing](/integration/react#close-before-replacing).

## Remove the integration

1. Stop mounting the loader.
2. Remove custom buttons and subscriptions.
3. Remove the containers.
4. Check browsing, cart and checkout.
5. Ask the Admin to retire unused keys.
6. Remove unused CSP allowances.

To close the account or delete data, ask your FittingMe contact.
