`window.FittingMe` exists after the loader accepts its first script tag. Before that, use the loader attributes. Pass the container or iframe element, not a selector.

```javascript
const container = document.getElementById('fittingme-widget-container');
// The loader script is async: wait up to 15 seconds for window.FittingMe.
(() => {
  let poll;
  const deadline = setTimeout(() => clearTimeout(poll), 15000);
  const connect = () => {
    const fm = window.FittingMe;
    if (!fm) {
      poll = setTimeout(connect, 100);
      return;
    }
    clearTimeout(deadline);
    const state = fm.resolve(container);
    // Call the other methods on fm here.
  };
  connect();
})();
```

## Methods

| Method | Returns | Behaviour |
| --- | --- | --- |
| `resolve(element)` | Snapshot or `undefined` | Reads a live embed. |
| `open(element)` | Verdict | Opens the drawer after an eligible bootstrap. |
| `close(element)` | Verdict | Closes the drawer. |
| `destroy(element)` | Verdict | Removes a closed embed. |
| `on(handler)` | Unsubscribe function | Subscribes to all embeds. Filter on `event.embed`. |

Commands return synchronously. `accepted` is not the result: watch the events. An `open` before bootstrap is refused, not queued. While the drawer is open, `close` then `destroy` at once returns `drawer_open` ([close before replacing](/integration/react#close-before-replacing)). `get()` is an older call form: use the element commands.

## Correlation identifier

`window.FittingMe.setCorrelationId(id)` sets the [Delivered Events](/reference/delivered-events#join-your-own-analytics) join value for all embeds on the page.

- Pass 1 to 128 characters that do not start with `FM_`. Pass `""`, `null` or `undefined` to clear it.
- The last value wins, from this method or [`data-correlation-id`](/reference/configuration#optional-attributes).
- An embed takes the value when its drawer opens.
- A refused value logs one warning and clears the identifier.
- Never put a personal identifier, such as an email address, in it.

## State snapshot

```javascript
// Shape returned by resolve(container); values shown are illustrative.
({
  embed: container,
  journey: 'tryon',
  outcome: 'eligible',
  drawer_open: false
});
```

`outcome` is `undefined` until bootstrap ends.

## Command verdicts

| Value | Meaning |
| --- | --- |
| `accepted` | The loader took the command. |
| `unknown_embed` | The element is not a known embed. |
| `embed_destroyed` | The embed was destroyed. |
| `bootstrap_incomplete` | Bootstrap is pending or indeterminate. |
| `embed_ineligible` | The embed cannot open. |
| `fullscreen_unavailable` | A parent element blocks fullscreen layout. |
| `drawer_open` | Destroy was called while the drawer was open. |

## Subscribe

```javascript
// Inside connect() from the first example, once fm is set:
const unsubscribe = fm.on(event => {
  if (event.embed !== container) return;
  if (event.type === 'bootstrap') {
    const canOpen = event.outcome === 'eligible';
    // Update your button state using canOpen.
  }
});

// When this subscriber's owner is disposed:
unsubscribe();
```

On subscribe, the loader replays the last bootstrap outcome. It does not replay other events. The replay runs inside `on()`. Initialise your values before you call `on()`. Do not call the returned function from the replayed handler.
