<Note>These examples target the English v4 contract. Confirm v4 availability in your assigned environment before rollout. See [migration and temporary French compatibility](/reference/compatibility#temporary-french-compatibility).</Note>

Use this reference only when you own the iframe integration. The [loader](/start/quickstart) implements these responsibilities for the normal integration path.

The direct example in this guide supplies a garment image and uses **`fittingme/4`**. Use the loader for prepared-catalogue integration.

## Iframe URL

Start from `https://widget.fittingme.ai/tryon/` and use `URL.searchParams` to encode inputs.

| Parameter | Requirement |
| --- | --- |
| `api_base` | Required API base for the environment. |
| `retailer_key` | Required publishable retailer key. |
| `product_id` | Required product identifier. |
| `journey` | `tryon`. |
| `garment_image_url` | Required for this major-4 recipe; follows the [image URL rules](/integration/products#image-url-requirements). |
| `host_origin` | Exact `window.location.origin`, including the port when present; no path. |
| `loader_major` | `4`. |
| `trigger_mode` | `host` for a host-owned button. |
| `locale` | Optional `en` or `fr`. |

Set sandbox and permissions **before** assigning the iframe URL:

```html
<iframe title="Virtual try-on"
  sandbox="allow-downloads allow-forms allow-popups allow-popups-to-escape-sandbox allow-same-origin allow-scripts allow-storage-access-by-user-activation"
  allow="web-share"></iframe>
```

The actual document URL contains a retailer key. Exclude it from analytics, support logs, and screenshots of developer tools.

## Message envelope

```javascript
({ protocol: 'fittingme/4', message: 'open', payload: {} });
```

The envelope has exactly these three keys. `payload` is an object. Use only English message names and fields. Mixed French/English envelope keys or known payload fields are rejected; unknown additive fields are ignored.

Before processing a received message, verify **both** `event.source === iframe.contentWindow` and `event.origin === widgetOrigin`. A foreign frame must not be able to change your state or force a protocol-mismatch shutdown. Send messages using the exact target origin, never `*`.

## Messages

| Direction | `message` | `payload` | Required host action |
| --- | --- | --- | --- |
| Widget → host | `bootstrap` | `outcome`; optional `transport_code` and `drawer_geometry: true` | Enable opening only for `eligible`; distinguish ineligible from indeterminate. |
| Widget → host | `height` | `height_px`: number | Save the closed height and apply it when not fullscreen. Zero is valid. |
| Widget → host | `opened` | Optional `opening_id` counter | Expand the iframe, lock page scrolling, and manage host-command history. |
| Widget → host | `closed` | Empty object | Restore in-flow height, scrolling, focus, and the appropriate history state. |
| Widget → host | `completed` | Empty object | Observe a completed result at close, after `closed`; not a unique generation count. |
| Host → widget | `open` | Empty object for this recipe | Request opening after eligibility; do not resend while open. |
| Host → widget | `close` | Empty object | Request closure. Observe the closing announcement. |
| Host → widget | `layout` | `capability: 'drawer_geometry'`; optional `opening_id`, `width_px`, `height_px` | Negotiate geometry when offered and acknowledge the corresponding opening after layout. |

Public loader events and wire messages are different interfaces. Wire envelopes do not carry `embed`; the parent already knows its iframe. The loader adds the container identity and opening origin when publishing its own events.

## Geometry negotiation

An initial `height` message with `height_px: 0` acknowledges English protocol support before API bootstrap; it does not establish eligibility.

When bootstrap announces `drawer_geometry: true`, the host can acknowledge that capability with `layout`. When the widget later supplies an `opening_id` counter, expand the iframe, allow layout to settle, then return that same counter with the actual viewport width and height in pixels. Do not reuse measurements from a previous opening.

## Host responsibilities

- Validate message origin, source, protocol, shape, and known names.
- Stop communicating with an established peer that announces an incompatible major; do not silently downgrade.
- Mount with zero height until the widget reports its closed height.
- Keep the fullscreen iframe outside ancestors that clip or redefine fixed positioning.
- Coordinate siblings if your application supports multiple direct embeds.
- Pair opening and closing, preserve page scroll styles, restore focus, and handle Back.
- Apply bounded UI timeouts for missing bootstrap or opening confirmation.
- Close before replacing the product/image; release your listeners and iframe on disposal.

The [completion timing and duplicate limits](/reference/events#completion-is-not-conversion) also apply to direct protocol events. `locale` configures the widget, not the separate phone capture page.

See the [complete direct example](/integration/direct-embed). Extend it only after testing these responsibilities in your actual application.
