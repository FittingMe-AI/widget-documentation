Load `https://widget.fittingme.ai/v5/fittingme-loader.js` once per embed, with its attributes on that script.

## Required attributes

| Attribute | Value |
| --- | --- |
| `data-api-base` | Normally `https://api.fittingme.ai`. |
| `data-retailer-key` | Publishable key authorised for your hostname. |
| `data-product-id` | Your product identifier. |
| `data-garment-image-urls` | One HTTPS URL or a JSON array of URLs of the same product and colour. |
| `data-journey` | `tryon`. |

A missing or blank value prevents mounting, except for `data-garment-image-urls`. Without an image attribute, the embed sends no page photo.

## Optional attributes

| Attribute | Default | Use |
| --- | --- | --- |
| `data-garment-image-url` | None | Deprecated one-photo alias. |
| `data-container` | `#fittingme-widget-container` | Selector of the existing container. |
| `data-trigger-mode` | `host` | `widget` shows the FittingMe entry point. |
| `data-locale` | French | `en` or `fr`. |
| `data-correlation-id` | None | Your join value for [Delivered Events](/reference/delivered-events#join-your-own-analytics). |
| `data-widget-url` | `https://widget.fittingme.ai/tryon/` | Widget document override. |

## Validation

- An unknown `data-*` attribute logs an error, and the embed does not mount.
- `data-garment-image-urls` needs the `/v5/` loader. On an older loader, the embed does not mount.
- The plural value is a plain URL or a JSON array. The loader trims it, removes duplicates in order and skips invalid members.
- Each URL uses HTTPS and has at most 1,024 characters.
- If both image attributes are present, the loader logs a developer error. The plural wins.
- Catalogue photos come first. Page photos are the fallback.
- An unknown locale falls back to French. Set `data-locale` explicitly.
- `data-correlation-id` has 1 to 128 characters and does not start with `FM_`. The loader reads it as written. A refused value logs one warning, and the embed still mounts. To change it, call [`setCorrelationId(id)`](/reference/javascript#correlation-identifier).

Do not add `data-host-origin` or `data-loader-major`. Set `data-trigger-mode="widget"` explicitly. An omitted, empty or unknown value gives host mode.

## Lifetime

The loader reads the attributes once, when the script executes. Use one unique container per embed, before the script. To change products, see [single-page and dynamic storefronts](/integration/react).
