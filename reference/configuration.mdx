Load `https://widget.fittingme.ai/v5/fittingme-loader.js` once **per embed**, with its configuration on that script element. Each script mounts one iframe into an existing container.

<Note>The multiple-view contract below is a draft for a compatible loader, widget, and API release. Confirm availability in your assigned environment before using it. The current published `/v4/` contract remains available for existing integrations.</Note>

## Required attributes

| Attribute | Value | Requirement |
| --- | --- | --- |
| `data-api-base` | API base URL, normally `https://api.fittingme.ai` | Must match the key's environment. |
| `data-retailer-key` | Publishable retailer key | Required; use the key authorised for the storefront hostname. |
| `data-product-id` | Merchant product identifier | Required even when supplying a garment image. |
| `data-journey` | `tryon` | Required for the integration in this guide. |

Missing or blank required inputs prevent mounting. There is no implicit journey choice.

## Optional attributes

| Attribute | Default when omitted | Behaviour |
| --- | --- | --- |
| `data-garment-image-urls` | Catalogue lookup | One HTTPS image URL or a JSON array of URLs showing views of the same product and colour. Catalogue imagery takes priority. |
| `data-garment-image-url` | Catalogue lookup | Deprecated one-photo alias. Supported until removal is separately announced; do not use it for new integrations. |
| `data-container` | `#fittingme-widget-container` | CSS selector resolving to the existing container. Its contents belong to FittingMe. |
| `data-trigger-mode` | Host-owned trigger | `widget` for the FittingMe entry point; `host` for a button controlled by your page. |
| `data-locale` | French fallback | Widget language: `en` or `fr`; supported regional forms fall back to their base language. The separate phone capture page uses its browser’s language. |
| `data-widget-url` | `https://widget.fittingme.ai/tryon/` | Explicit widget document override for an assigned environment. Keep loader, widget, and API compatible. |

`data-sizing-domain` belongs to the separate Sizing integration and is unnecessary for try-on.

## Validation and forwarding

- The loader accepts a closed list of `data-*` attributes. Do not attach analytics or framework metadata to this script; put it on your own element instead.
- The plural value may be one plain URL or a JSON array of URL strings. A JSON-encoded string, object, scalar, `null`, or malformed JSON is invalid. An empty, blank, or `[]` plural value uses catalogue lookup.
- Each candidate is trimmed before validation and ordered deduplication. Internal whitespace, credentials, fragments, non-HTTPS URLs, and URLs over 1,024 Unicode characters before or after serialization remain invalid. Invalid array members are skipped without coercion.
- If both image attributes are present, the loader reports a developer error and uses only the plural value, even when that value is empty or invalid. It never merges or recovers the singular value.
- Catalogue images are preferred when usable. Supplied views are a fallback, never additional views in a catalogue set. Unusable supplied configuration still permits eligible catalogue imagery; if no eligible image is available, the existing unavailable state applies.
- Unknown `data-*` attributes and unsupported journeys are rejected in the console.
- An unknown locale falls back; it does not create a new translation. Set `data-locale="en"` explicitly for an English storefront.
- `data-container` and `data-widget-url` configure the loader; they are not forwarded as widget query parameters.
- The loader derives `host_origin` from the page and chooses the message protocol major. Do not add `data-host-origin` or `data-loader-major`.

The `/v5/` loader uses `fittingme/5` English messages and requires an explicit plural capability acknowledgement from the widget and API. Older peers cannot silently accept one view. Artifact paths and wire majors are separate contracts. Set `data-trigger-mode="widget"` explicitly to show the widget trigger. Omission, empty and unknown values retain host mode. Deprecated French trigger aliases are described in [migration guidance](/reference/compatibility#temporary-french-compatibility).

## Lifetime

All inputs are read when that script executes. Changing the script's attributes afterwards has no effect. See [product changes](/integration/product-changes) for replacement.

If the selector does not find a container, nothing is mounted. If another live embed already owns the element, the duplicate is ignored. Use one unique container per embed and insert it before the script.

See [the complete quickstart](/start/quickstart) for copyable HTML, [image requirements](/integration/products#image-url-requirements), and [JavaScript methods](/reference/javascript).
