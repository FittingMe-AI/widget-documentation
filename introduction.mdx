FittingMe delivers two independent Shopper Journeys on retailer product pages: the **Sizing Journey** and the **Try-On Journey**. Each journey is placed as its own Journey Embed, with its own trigger, drawer, and session.

The public integration surface is a standalone loader script. A loader tag reads a bounded set of `data-*` attributes, mounts one iframe in the selected container, and connects the host page to one journey.
