Fitting Me is a developer API service that lets you create, manage, and customize embeddable widgets for your web applications. Whether you're building a product configurator, a booking tool, or an interactive embed, Fitting Me gives you programmatic control over widget keys and their visual appearance through a straightforward REST API. It's built for developers who need flexibility without complexity — get up and running in minutes and tailor every pixel with plain CSS.

## What you can do

Fitting Me is designed to give you complete control over your widgets from a single API. Here's a snapshot of what's available today — with more on the way.

<CardGroup cols={2}>
  <Card title="Create & manage widget keys" icon="circle-plus">
    Generate unique keys for each widget instance and manage their lifecycle — create, update, or delete them at any time.
  </Card>
  <Card title="Customize widget CSS styles" icon="brush">
    Push custom CSS directly to any widget key so every embed looks exactly the way you designed it.
  </Card>
  <Card title="Multiple widgets per account" icon="layer-group">
    Run as many widget keys as your project requires. Each key is independently configurable with its own styles and settings.
