---
title: "DELETE /widget-keys/:id — Remove a Widget Key"
sidebarTitle: "Delete Key"
description: "DELETE /widget-keys/:id — permanently delete a Fitting Me widget key. This action cannot be undone and stops all embeds using this key."
---

Use this endpoint to permanently remove a widget key from your Fitting Me account. Once deleted, any embed on your site that references this key's token will stop rendering the widget immediately.

<Warning>
  Deleting a widget key is permanent and cannot be undone. All pages embedding the widget with this key's token will stop working as soon as the key is deleted. Make sure you have removed or replaced the embed code on your site before proceeding.
</Warning>

## Endpoint

```
DELETE https://api.fitting.me/v1/widget-keys/:id
```

## Headers

<ParamField header="Authorization" type="string" required>
  Your Fitting Me API key, supplied as `Bearer YOUR_API_KEY`.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the widget key you want to permanently delete.
</ParamField>

## Example Request

```bash
curl --request DELETE \
  --url https://api.fitting.me/v1/widget-keys/wk_01HXYZ1234ABCDEF567890 \
  --header "Authorization: Bearer YOUR_API_KEY"
```

## Response

A successful deletion returns a `204 No Content` status with an empty response body, confirming the widget key has been permanently removed.

## Error Responses

| Status | Description |
|--------|-------------|
| `404 Not Found` | No widget key with the supplied ID exists on your account. Verify the ID and ensure you are using the correct API key. |
| `401 Unauthorized` | The `Authorization` header is missing or your API key is invalid. |

<Tip>
  If you want to temporarily stop a widget from rendering without permanently losing the key, consider setting `active` to `false` via the [Update Key](/api-reference/widget-keys/update) endpoint instead. You can reactivate the key at any time.
</Tip>
