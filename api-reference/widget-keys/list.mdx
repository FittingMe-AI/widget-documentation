Use this endpoint to retrieve all widget keys associated with your Fitting Me account. The response is paginated, so you can use the `limit` and `offset` parameters to page through large result sets. You can also filter results to show only active or inactive keys.

## Endpoint

```
GET https://api.fitting.me/v1/widget-keys
```

## Headers

<ParamField header="Authorization" type="string" required>
  Your Fitting Me API key, supplied as `Bearer YOUR_API_KEY`.
</ParamField>

## Query Parameters

<ParamField query="limit" type="number">
  The maximum number of widget keys to return per page. Defaults to `20`. Maximum allowed value is `100`.
</ParamField>

<ParamField query="offset" type="number">
  The number of records to skip before returning results, used for paginating through large result sets. Defaults to `0`.
</ParamField>

<ParamField query="active" type="boolean">
  Filter results by active status. Pass `true` to return only active keys, or `false` to return only inactive keys. Omit this parameter to return all keys regardless of status.
</ParamField>

## Example Request

```bash
curl --request GET \
  --url "https://api.fitting.me/v1/widget-keys?limit=20&offset=0&active=true" \
  --header "Authorization: Bearer YOUR_API_KEY"
```

## Response

A successful request returns a `200 OK` status and a paginated response object.

<ResponseField name="data" type="array">
  An array of widget key objects matching your query. Each object has the same shape as the response from the [Get Key](/api-reference/widget-keys/get) endpoint.
</ResponseField>

<ResponseField name="total" type="number">
  The total number of widget keys on your account that match the applied filters, regardless of the current page size.
</ResponseField>

<ResponseField name="limit" type="number">
  The maximum number of results returned for this page, reflecting the `limit` parameter you supplied (or the default of `20`).
</ResponseField>

<ResponseField name="offset" type="number">
  The pagination offset used for this response, reflecting the `offset` parameter you supplied (or the default of `0`).
</ResponseField>

## Error Responses

| Status | Description |
|--------|-------------|
| `400 Bad Request` | A query parameter has an invalid value — for example, `limit` exceeds `100` or `active` is not a boolean. |
| `401 Unauthorized` | The `Authorization` header is missing or your API key is invalid. |

<Tip>
  To retrieve the next page of results, increment `offset` by the value of `limit`. For example, if you requested `limit=20` and received 20 results, pass `offset=20` in your next request to fetch the following page.
</Tip>
