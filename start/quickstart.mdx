Complete the [prerequisites](/start/prerequisites).

## 1. Replace three values

| Placeholder | Replace with |
| --- | --- |
| `YOUR_PUBLISHABLE_KEY` | Your retailer key. |
| `YOUR_PRODUCT_ID` | The product identifier. |
| `https://images.example.com/YOUR_GARMENT.jpg` | A public HTTPS image URL, in both places. |

FittingMe must approve your origin for framing. Use a direct image URL that meets the [image requirements](/integration/products#image-url-requirements). In HTML, write `&` as `&amp;`.

## 2. Add the page

Save it as `try-on.html`.

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Try on this garment</title>
  <style>
    body { margin: 0; padding: 24px; font: 16px/1.6 system-ui, sans-serif; }
    main { max-width: 480px; margin: auto; }
    .product-image { display: block; width: 100%; height: auto; }
  </style>
</head>
<body>
  <main>
    <h1>Example garment</h1>
    <img class="product-image"
      src="https://images.example.com/YOUR_GARMENT.jpg"
      alt="The garment available to try on">
    <div id="fittingme-widget-container"></div>
  </main>
  <script async src="https://widget.fittingme.ai/v5/fittingme-loader.js"
    data-api-base="https://api.fittingme.ai"
    data-retailer-key="YOUR_PUBLISHABLE_KEY"
    data-product-id="YOUR_PRODUCT_ID"
    data-garment-image-urls="https://images.example.com/YOUR_GARMENT.jpg"
    data-journey="tryon"
    data-locale="en"
    data-trigger-mode="widget"
    data-container="#fittingme-widget-container"></script>
</body>
</html>
```

For several views, put the front view first:

```html
data-garment-image-urls='["https://images.example.com/FRONT.jpg","https://images.example.com/BACK.jpg"]'
```

Serve it from an allowed hostname. With a `localhost` key, run:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Open `http://localhost:8080/try-on.html`.

## 3. Verify the result

1. Load the page. The FittingMe button appears.
2. Open try-on. The drawer shows without clipping.
3. Complete the consent and photo steps.
4. Start generation. The result appears.
5. Close the drawer. The page scrolls normally.

Success: the **correct garment appears in a completed result**, and the shopper can return.

## If it does not work

| Observation | First check |
| --- | --- |
| No button | Container order, rejected attributes or `frame-ancestors` in the console. |
| Try-on fails | Image type, size, redirects and access without sign-in. |
| Access failure | Key, environment, hostnames and try-on access. |
| Drawer clipped or opening refused | [Ancestor transforms](/troubleshooting/symptoms#the-drawer-is-clipped-or-refuses-to-open). |
