---
title: "Place multiple Journey Embeds"
sidebarTitle: "Multiple Journey Embeds"
description: "Place independent Sizing and Try-On Journey Embeds on the same product page."
---

A product page may offer Sizing, Try-On, or both. Each Journey Embed needs its own container and loader tag because it owns a separate trigger, drawer, and session.

```html
<!-- Sizing Journey -->
<div id="fittingme-sizing"></div>
<script
  async
  src="https://cdn.fittingme.ai/fittingme-widget/loader/fittingme-loader.min.js"
  data-container="#fittingme-sizing"
  data-api-base="https://api.fittingme.ai"
  data-retailer-key="YOUR_PUBLISHABLE_KEY"
  data-product-id="YOUR_PRODUCT_SKU"
  data-locale="en"
  data-journey="sizing"
></script>

<!-- Try-On Journey -->
<div id="fittingme-tryon"></div>
<script
  async
  src="https://cdn.fittingme.ai/fittingme-widget/loader/fittingme-loader.min.js"
  data-container="#fittingme-tryon"
  data-api-base="https://api.fittingme.ai"
  data-retailer-key="YOUR_PUBLISHABLE_KEY"
  data-product-id="YOUR_PRODUCT_SKU"
  data-locale="en"
  data-journey="tryon"
></script>
```

<Note>
  Both embeds mount their iframe from `https://widget.fittingme.ai/<journey>/` — `/sizing/`
  for the first, `/tryon/` for the second. One origin covers both, so allowing it once in
  your CSP covers every Journey Embed on the page. See
  [Artifact origin and framing](/guides/integration).
</Note>

The loader keeps all live handles in one page-level registry. After both scripts have executed, you can resolve either embed by journey:

```javascript
const sizing = window.FittingMe.get('sizing');
const tryOn = window.FittingMe.get('tryon');

sizing?.open();
tryOn?.close();
```

Opening one drawer closes an open sibling drawer. Destroying one handle does not remove the other embed.

<Warning>
  Never point two loader tags at the same resolved container element. The loader treats the second tag as a duplicate and ignores it.
</Warning>
