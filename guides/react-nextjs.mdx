Use a client component for a retailer-owned button. Access `window` and `document` in an Effect, and include immutable product/image inputs in its dependencies. React rerenders do not reconfigure an existing embed. See React's [Effect lifecycle](https://react.dev/reference/react/useEffect) and Next.js's [`use client` boundary](https://nextjs.org/docs/app/api-reference/directives/use-client).

The integration below keeps the zero-height iframe container directly under `body`, outside React's removable product subtree. That lets cleanup wait for a real close even after React removes the button. It serializes replacement for this component and ignores obsolete callbacks. The loader still owns the drawer and inter-embed coordination.

## Add the client component

### Save the component

Save this as `TryOn.jsx`. It uses ordinary React and the public loader; it is not a FittingMe React SDK. Replace the placeholders at the call site below.

```jsx
"use client";

import { useEffect, useRef, useState } from "react";

export default function TryOn({ retailerKey, productId, imageUrl, locale = "en" }) {
  const buttonRef = useRef(null);
  const queue = useRef(Promise.resolve());
  const [view, setView] = useState({ ready: false, busy: false, text: "Loading Try-On…" });

  useEffect(() => {
    let active = true;
    let controller;
    const notify = patch => {
      if (active) setView(previous => ({ ...previous, ...patch }));
    };
    notify({ ready: false, busy: false, text: "Loading Try-On…" });
    const started = queue.current.then(async () => {
      if (!active) return; // Handles obsolete work, including Strict Mode replay.
      controller = await mount({
        retailerKey, productId, imageUrl, locale,
        button: buttonRef.current, notify, isActive: () => active
      });
    });
    started.catch(() => notify({ ready: false, text: "Try-On could not initialize." }));

    return () => {
      active = false;
      // React cleanup is synchronous. The owned body-level placement remains
      // connected until this asynchronous close-before-destroy finishes.
      queue.current = started.then(() => controller?.dispose());
      queue.current.catch(() => {
        console.warn("Try-On cleanup did not complete; its owned embed was retained.");
      });
    };
  }, [retailerKey, productId, imageUrl, locale]);

  return (
    <section aria-label="Virtual try-on">
      <button ref={buttonRef} type="button" hidden={!view.ready} disabled={view.busy}>
        Try it on
      </button>
      <p role="status">{view.text}</p>
    </section>
  );
}

async function mount({ retailerKey, productId, imageUrl, locale, button, notify, isActive }) {
  const placement = document.createElement("div");
  placement.id = "tryon-" + crypto.randomUUID();
  document.body.append(placement);
  const script = document.createElement("script");
  script.src = "https://widget.fittingme.ai/v2/fittingme-loader.js";
  const attributes = {
    "data-api-base": "https://api.fittingme.ai",
    "data-retailer-key": retailerKey,
    "data-product-id": productId,
    "data-journey": "tryon",
    "data-locale": locale,
    "data-trigger-mode": "hôte",
    "data-container": "#" + placement.id
  };
  if (imageUrl !== undefined) attributes["data-garment-image-url"] = imageUrl;
  for (const [name, value] of Object.entries(attributes)) script.setAttribute(name, value);
  const reminder = setTimeout(() => notify({ text: "Try-On is still loading. Check the network." }), 20000);
  // A late load still has an owner: do not assume removing a script cancels it.
  await new Promise((resolve, reject) => {
    script.onload = resolve;
    script.onerror = () => {
      clearTimeout(reminder); script.remove(); placement.remove();
      reject(new Error("Loader failed"));
    };
    document.body.append(script);
  });
  const api = window.FittingMe;
  if (!api?.resolve(placement)) {
    clearTimeout(reminder); script.remove(); placement.remove();
    throw new Error("Embed did not mount");
  }
  let pendingOpen = null, disposing = false, disposal = null;
  const unsubscribe = api.on(event => {
    if (event.encart !== placement) return;
    if (event.jalon === "amorçage") {
      clearTimeout(reminder);
      notify({ ready: event.issue === "éligible", text: event.issue === "éligible"
        ? "Try-On is ready." : event.issue === "inéligible"
          ? "Try-On is unavailable for this product." : "Try-On could not load." });
    }
    if (event.jalon === "fermeture" && isActive() && !disposing && button.isConnected) button.focus();
  });
  function observe(name, command) {
    return new Promise((resolve, reject) => {
      const timer = setTimeout(() => finish(new Error("Transition not observed")), 2500);
      const off = api.on(event => {
        if (event.encart === placement && event.jalon === name) finish();
      });
      function finish(error) {
        clearTimeout(timer); off();
        if (error) reject(error); else resolve();
      }
      const verdict = command();
      if (verdict !== "accepté") finish(new Error("Command refused: " + verdict));
    });
  }
  function open() {
    if (!isActive() || disposing || pendingOpen || api.resolve(placement)?.tiroir_ouvert) return;
    notify({ busy: true });
    pendingOpen = observe("ouverture", () => api.open(placement));
    pendingOpen.catch(() => notify({ text: "Opening was not observed. Check the integration." }))
      .finally(() => { pendingOpen = null; notify({ busy: false }); });
  }
  button.addEventListener("click", open);
  function dispose() {
    if (disposal) return disposal;
    disposing = true;
    button.removeEventListener("click", open);
    disposal = (async () => {
      if (pendingOpen) await pendingOpen;
      if (api.resolve(placement)?.tiroir_ouvert) {
        await observe("fermeture", () => api.close(placement));
        await new Promise(resolve => setTimeout(resolve, 0));
      }
      const verdict = api.destroy(placement);
      if (verdict !== "accepté") throw new Error("Teardown refused: " + verdict);
      unsubscribe(); clearTimeout(reminder);
      script.onload = script.onerror = null;
      script.remove(); placement.remove();
    })();
    return disposal;
  }
  return { dispose };
}
```

### Render with stable props

Render it with stable primitive props and replace the placeholders:

```jsx
<TryOn
  retailerKey="YOUR_PUBLISHABLE_KEY"
  productId="YOUR_PRODUCT_ID"
  imageUrl="https://images.example.com/YOUR_GARMENT.jpg"
  locale="en"
/>
```

Omit `imageUrl` only for a [prepared catalogue](/guides/prepared-catalogue) product. A client component's public key is visible to browsers; never pass a server credential into it. For another service environment, change both the API and widget address consistently in the mount configuration.

## Product changes and navigation

Changing `productId` or `imageUrl` starts cleanup before a replacement is mounted. Unchanged primitive props do not remount just because a parent rerenders. Each effect generation has its own container and listener. Do not use a framework script helper that deduplicates away the script execution needed for a new embed.

### Coordinate planned navigation

1. Put lifecycle ownership in your persistent application shell.
2. While the drawer is open, await disposal **before** committing the route. The component's cleanup is a fallback for unmounts, not a router guard: React does not await asynchronous cleanup.
3. If the trigger no longer exists after navigation, focus a suitable heading or control on the destination page through your router's normal focus management.

### Keep failed or pending work owned

An unresolved close keeps its owned placement connected and prevents this component's queued replacement. Surface that failure and investigate it rather than deleting an open iframe. A loader download that remains pending likewise stays owned; the status reminder does not claim it failed or that it is safe to forget it. Add your application's retry/recovery policy around this behavior.

## Tracking and verification

1. Add the [usage adapter](/tracking/usage) after `api` is available, using the effect generation's fixed product identity.
2. Store its unsubscribe function beside the UI subscription and release both after close/completion. Keep analytics consent state current without reinstalling listeners on every render.

### Verify the component lifecycle

1. Run in development Strict Mode and rerender with unchanged props.
2. Make two successive product changes.
3. Navigate while opening, and test an unmount while the drawer is open.

Expect no stale button, no duplicate events and no orphan iframe after successful cleanup. Use the [go-live checks](/testing/go-live) against the real services. Advanced consumers replacing the loader must implement the separate [fittingme/3 contract](/reference/fittingme-3).
