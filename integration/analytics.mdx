## Decide what to measure

| Question | Evidence |
| --- | --- |
| Can this product offer try-on? | `bootstrap` with `outcome: 'eligible'`. |
| Did a shopper open try-on? | `opened`. |
| Did the drawer close? | `closed`. |
| Did it close on a completed result? | [`completed`](/reference/events#completion-is-not-conversion), after `closed`. |
| How many renders were shown? | Distinct `try_on_reference` values of `tryon_result_revealed`. [Indicative, never an invoice](/reference/events#shown-try-on-renders). |
| Did the shopper buy? | Your own cart and order events. |

A replayed `bootstrap` is not a shopper visit.

## Add a tracking adapter

Run this code after the loader loads, before you enable a custom trigger.

```javascript
const container = document.getElementById('fittingme-widget-container');
const productId = 'YOUR_PRODUCT_ID';
let analyticsAllowed = false;

// Connect this function to your storefront's consent manager.
function setTryOnAnalyticsConsent(allowed) {
  analyticsAllowed = allowed === true;
}

const eventNames = {
  opened: 'fittingme_opened',
  closed: 'fittingme_closed',
  completed: 'fittingme_completed_result_closed',
  tryon_result_revealed: 'fittingme_tryon_result_revealed',
};

const unsubscribe = window.FittingMe.on(event => {
  if (event.embed !== container || !analyticsAllowed) return;
  const name = eventNames[event.type];
  if (!name) return;
  const record = { event: name, product_id: productId };
  if (event.type === 'opened') record.open_origin = event.origin;
  if (event.type === 'tryon_result_revealed') record.try_on_reference = event.try_on_reference;
  window.dataLayer = window.dataLayer || [];
  window.dataLayer.push(record);
});

// Keep this subscription for the lifetime of the page-owned embed.
// Do not unsubscribe in a closed handler: completed can follow.
```

The four names are yours, and the `dataLayer` push configures no destination.

Never send the DOM element, retailer key, full iframe URL, capture link, session capability, shopper photo or result URL. Keep one subscription per owner for the embed's lifetime. Check consent at dispatch time.

## Verify the measurements

1. Refuse consent and complete a journey. Expect no record.
2. Give consent and complete a new journey.
3. Close the drawer: expect `closed`, then `completed`, with your product. Reopen and close: expect nothing.
4. Keep the drawer open on a render. Expect one `fittingme_tryon_result_revealed` with a 32-character `try_on_reference`.
5. Re-run the try-on. Expect a new reference.
6. Reopen, then reload on that render. Expect no record.
7. Reload and close a completed result: expect a completion, not a new try-on. Close during generation, then reopen: expect one record. Subscribe late: expect none.
8. Compare purchases with your order events. A completion is never a conversion.
