## Choose the trigger

| Mode | Configuration | You |
| --- | --- | --- |
| FittingMe button | `data-trigger-mode="widget"` | Place the container. |
| Your button | `data-trigger-mode="host"` | Render a button, wait for eligibility, then call `open(container)`. |

Host mode also needs the container, even at zero closed height.

## Complete custom-button example

Replace the three [quickstart](/start/quickstart) values.

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Try on this garment</title>
</head>
<body>
  <main>
    <h1>Example garment</h1>
    <img src="https://images.example.com/YOUR_GARMENT.jpg" alt="Garment">
    <button id="try-on" type="button" disabled aria-describedby="try-on-status">
      Try it on
    </button>
    <p id="try-on-status" role="status">Checking try-on availability…</p>
    <div id="fittingme-widget-container"></div>
  </main>
  <script async src="https://widget.fittingme.ai/v5/fittingme-loader.js"
    data-api-base="https://api.fittingme.ai"
    data-retailer-key="YOUR_PUBLISHABLE_KEY"
    data-product-id="YOUR_PRODUCT_ID"
    data-garment-image-urls="https://images.example.com/YOUR_GARMENT.jpg"
    data-journey="tryon"
    data-locale="en"
    data-trigger-mode="host"
    data-container="#fittingme-widget-container"></script>
  <script>
    const container = document.getElementById('fittingme-widget-container');
    const button = document.getElementById('try-on');
    const status = document.getElementById('try-on-status');
    (() => {
      let poll;
      const deadline = setTimeout(() => {
        clearTimeout(poll);
        status.textContent = window.FittingMe ?
          'Try-on is taking longer than expected. Please reload to retry.' :
          'Try-on could not load. Please reload the page.';
      }, 15000);
      // The loader script is async: wait until window.FittingMe exists.
      const connect = () => {
        const fm = window.FittingMe;
        if (!fm) {
          poll = setTimeout(connect, 100);
          return;
        }
        const unsubscribe = fm.on(event => {
          if (event.embed !== container) return;
          if (event.type === 'bootstrap') {
            clearTimeout(deadline);
            button.disabled = event.outcome !== 'eligible';
            status.textContent = event.outcome === 'eligible' ? '' :
              event.outcome === 'ineligible' ? 'Try-on is unavailable for this product.' :
              'Try-on is temporarily unavailable. Please reload to retry.';
          }
          if (event.type === 'closed') button.focus();
        });
        button.addEventListener('click', () => {
          const verdict = fm.open(container);
          if (verdict !== 'accepted') {
            status.textContent = 'Try-on could not open. Please try again.';
          }
        });
        // A full page navigation releases this document and its subscription.
        // A SPA must call unsubscribe() as part of its component cleanup.
      };
      connect();
    })();
  </script>
</body>
</html>
```

The 15-second message is an example, not a service promise.

## Set the language

Set `data-locale="en"` or `data-locale="fr"`. The value is case-insensitive, and `en-GB` falls back to `en`. An unknown value gives French, so always set it.

A new language needs a new embed. Translate your own button text. The phone capture page uses the language of the phone.

## Styling boundary

Storefront CSS does not restyle the iframe. Arrange branding with FittingMe. Keep the container out of [transformed ancestors](/troubleshooting/symptoms#the-drawer-is-clipped-or-refuses-to-open).

**Verify:** keyboard use, focus after close, a failed bootstrap, both languages and the mobile layout.
